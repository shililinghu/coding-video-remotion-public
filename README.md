# coding-video-remotion-public

Code generated video renderer and timeline tools.

This public edition contains reusable source only, with independent Git history. Read [PRIVACY.md](PRIVACY.md) before configuring it.

Original runtime configuration, personal data and media are intentionally absent. Install dependencies listed by the included package or requirements files and supply your own local settings. Examples are fictional.

## Usage

In `app/`, run `npm test` and `npm run serve`. This edition includes a newly generated fictional narration fixture for timeline validation. It is not the original production script or a finished narrated video. Optional fonts and audio are supplied by the user; system fonts work for a silent preview.
